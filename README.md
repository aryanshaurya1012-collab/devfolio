# Devfolio

A modern, responsive React portfolio built with Vite and custom CSS.

## Getting started

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Personalizing the site

Update the content in `src/data/portfolio.js`:

- Personal name, introduction, email, and social links
- Skills and technology groups
- Project titles, descriptions, categories, and URLs

The visual system is defined in `src/styles/globals.css`. The site includes a persisted dark/light theme toggle, responsive navigation, reduced-motion support, and project filtering.
